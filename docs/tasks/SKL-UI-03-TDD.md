# SKL-UI-03 task design

Date: 2026-08-22
Card: `ecf6d536`
Size: L

## Objective

Preserve the completed full-product wireframe and create a version 2 Matter
cockpit that turns the private HowToWinInCourt corpus into ranked,
source-grounded next-step proposals. Make AI the default operating layer while
retaining the approved gates that bind facts, strategy, artifact versions, and
external actions.

## Dependencies

- `SKL-S0-01`
- `HTWC-S5-05`
- `SKL-UI-02`

## Implementation

- Review the verified corpus architecture, approved SKLegal boundaries, model
  gateway, domain records, current workspace, and instruction files.
- Show intake, Matter type and Proceeding phase routing, essential Elements,
  burden of proof, Fact Assertions, Evidence Items, course instruction,
  current Authority, counter-support, record gaps, ranked proposals,
  challenge, human decision, Work Product assembly, provider route evidence,
  Deadline handling, and external-action gates.
- Show a simple Matter artifact intake and request flow that preserves the
  original bytes, hash, source identity, custody, extraction lineage, review
  state, and every link into the case theory.
- Show a complete Matter activity log spanning legal chronology, AI and tool
  activity, human decisions, artifact lineage, Approvals, connector events,
  receipts, and replay or export evidence.
- Reconcile HammerTime's Qwen-first and anti-label principles into SKLegal
  instructions without importing HammerTime-specific legal conclusions or
  weakening SKLegal controls.

## Tests

- Static HTML structure and version linkage
- Required evidence lanes and Matter activity log
- Artifact intake, request, lineage, and production-bundle concepts
- No remote wireframe assets
- ASCII-dash validation
- Synthetic-content markers and model-boundary language
- Exact card reference

## Acceptance

- The new deck opens locally without a build step.
- Every material source class is visibly separate.
- Current and missing backend contracts are labeled.
- Model output remains a typed proposal.
- Routine analysis, gap detection, artifact organization, and drafting are AI
  driven by default.
- Every consequential action links to deterministic validation and human
  Approval.
- A reviewer can reconstruct what happened, what changed, what sources and
  model runs were used, who decided, and which exact artifact was acted upon.

## Prohibited

- HammerTime `Inbox/` access or corpus mutation
- Protected Matter data
- Production deployment or external account creation
- Outbound legal action
- Hard-coded private model endpoints
- Commit or push
