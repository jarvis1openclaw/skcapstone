Decisions already made

This approved design incorporates the confirmed product direction. The retrieval data plane was amended on 2026-08-21 to use separate local core and retrieval PostgreSQL clusters.

Product

SKLegal

A local-first law-firm application with a React frontend, proper legal terminology, and GPLv3 licensing.

Tenancy

Firm, client, matter

Tenants are security boundaries. Casey, David, relatives, trusts, and trustees are clients or party roles unless separate tenancy is actually required.

Corpus

HammerTime remains canonical

Originals, provenance, decomposition, and releases stay in HammerTime during the first migration.

Models

Qwen local, OpenAI optional

Qwen performs local corpus analysis. OpenAI is a policy-controlled API route for approved roles and context.

Authorization

CapAuth from foundation

Every protected API, retrieval, model tool, approval, and connector action requires a signed scoped capability.

Delivery

One verified slice at a time

Features progress through tests and evidence. Subagents start only after architecture approval.

System architecture

SKLegal owns operational legal work. HammerTime owns corpus custody. Durable workflows, policy gates, and deterministic reducers sit between humans, agents, sources, and consequential actions.

Legal terminology cutover

The application stops using ITIL-shaped labels for legal work. Legacy identifiers survive as source aliases, while every new API and screen speaks the legal domain.

LegacySKLegalMigration treatment
ProblemMatterOne-to-one default with source alias and path.
IncidentSemantic targetClassify as Matter Event, Transaction, Communication, Task, Evidence Event, or Proceeding.
Owner profileMatter membership and Party RoleSeeds a proposal, never grants access automatically.
Incident registryMatter registerGenerated from PostgreSQL and reconciled to source.
ResolutionDisposition or completed actionClassified by meaning and source.
Root causeFactual issue or causal theoryNo automatic migration. ITIL stays with platform operations.

First migration pattern

The Liberty Auto Plaza record becomes one SKLegal Matter with a transaction-review Matter Event, not a renamed Incident. The source remains untouched while SKLegal proves lossless projection and replay.

OpenAI

Approved API route

Uses a Platform API key, structured outputs, constrained tools, and explicit tenant egress policy. It is not a consumer ChatGPT browser session.

External actions are first-class

Email, filing, service, mailing, calendar, and client communications are designed now, tested in simulation, and activated one connector at a time only after qualification.

Prepare

Draft, validate source and destination, calculate required fields, and pin the exact artifact version.

Authorize

Verify capability, policy, approval, account, route, and any two-person or human confirmation requirement.

Reconcile

Queue idempotently, dispatch, capture provider response, verify receipt, and surface any unresolved delivery state.

Risks made explicit

The design blocks implementation where the current environment or assurance evidence is not yet good enough.

chiap01 capacity HIGH

Root storage is at 95 percent. Sprint 0 must remediate capacity before persistent deployment.

Tenant isolation HIGH

Casey, David, family, trust, and future client data must never rely on UI filters or profile metadata for isolation.

Consequential connectors HIGH

Filing, service, mailing, email, and calendar require exact-version approval, idempotency, destination verification, and receipts.

OpenAI egress CONTROLLED

Only approved, classified context may use the Platform API. Local Qwen remains the default protected corpus route.

Legacy meaning CONTROLLED

Incident records need semantic classification. The importer preserves ambiguity and asks for review.

Source and code rights CONTROLLED

Free access is not permission. Connectors, datasets, models, skills, and doc.haus components need pinned rights records.
